How the machine actually works

Free public data goes in at one end. Finished vertical videos in three languages come out the other. This is the map of what happens in between, what runs on its own, and where a human still has to stand.

The dotted arrow is the only gap left between "data exists" and "video is live".

Everything is free

No paid data feed anywhere. The exchanges and the grey-market desk publish open JSON; we just ask politely and cache.

The sheet is the truth

Not a database, not a copy — the store. The website reads the same spreadsheet the pipeline writes, so nothing can be stale relative to it.

The AI writes words

Never numbers. Every figure on screen traces to an exchange or a desk. That line is enforced in code, not by asking nicely.

02 — WHERE THE DATA COMES FROMFour sources, each with one job

They are deliberately not interchangeable. Each is authoritative for something and ignored for everything else — that separation is what makes a disagreement between them meaningful instead of confusing.

SourceAuthoritative forDeliberately NOT used for
InvestorGain Grey-market premium, the restated financials, reservation split, and the ticker (NSE symbol / ISIN / BSE code) Whether an IPO exists at all
NSE Issue terms, subscription, the trading calendar, index & sector levels, pre-open, gainers/losers GMP — no exchange publishes grey-market data, ever
BSE A second, independent yes/no on existence Prices, GMP, anything numeric
News RSS ×7 Overnight headlines in a stated 07:30→07:30 IST window Their photographs — copyright
Why two exchanges.

One missing feed is a blip. An IPO absent from both exchanges on a day it claims to be taking bids is a fabrication — and that has actually happened. Two agreeing sources is what makes an absence mean something.

Reel 7 needed a record that isn't a company. Rather than fake one, it got its own tabs.
The rule that keeps it honest: a blank cell means "nobody knows", never "zero".

These are different claims and confusing them invents facts. A peer P/E of 0 says the company's rivals earn nothing; a blank says we never found the figure. Until recently the sheet was writing zeros for both — 25 rows asserting a peer P/E of exactly nought. Now absent values write blank.

…except in a series, where position is the meaning.

Debt of [0, 4.36, 3.61] means a debt-free first year. Blank that zero and the list becomes [4.36, 3.61] — silently re-labelling one year's debt as another's. In a series, absence is expressed by the series being shorter, never by a hole in the middle.

04 — THE DAYWhat runs, and when

Windows Task Scheduler fires named jobs. Steps that read what the previous one wrote are chained, not scheduled apart and hoped for.

Time (IST)JobWhat it does
08:00market Builds tomorrow's pre-market briefing — after the news window shuts at 07:30, before the pre-open at 09:00
10:00 · 18:35daily The chain: sync → verify → dedupe → facts → enrich → doctor → build → validate
11:15 · 14:15 · 21:15gmp-sync Grey-market premium from the desk. Free, keyless, no AI
12:30 · 19:30 · 22:30monitor The watchdog — did anything change, and should it have?
23:45grey gmp-sync → gmp → build. The model only fills what the free source missed

05 — THE STUDIOSeven reels, one record

The website is not a report of the data — it is the data, rendered. It reads the spreadsheet directly in the browser. There is no published JSON in between, so a pipeline run shows up on the next reload.

Reel 1 · About IPO

Size, what the company does, fresh-vs-OFS split, who the book is reserved for, price band, dates.

Reel 2 · Daily GMP

Today's premium, the estimated listing, gain per lot, and the full dated trail.

Reel 3 · Subscription

QIB / NII / Retail demand and how it built day by day.

Reel 4 · Apply or Skip?

Three years of financials, valuation against peers, green and red flags, what a lot actually costs.

Reel 5 · Final Verdict

The score and the call — with the SEBI disclosure spoken before it, not after.

Reel 6 · Allotment & Listing

How to check allotment, the odds, the listing date.

Reel 7 · Market Today new

The odd one out: not about an IPO at all. Pre-market outlook, five overnight stories, which sectors look strong and weak, and ten intraday levels — five long, five short. Backend is live; its scenes aren't drawn yet.

The mirrored pairs — the thing most likely to bite

Why a reel is screenshots, not a screen recording.

The old way recorded the browser tab — which needs a human to click a "share this tab" dialog every single time. That is a browser security rule and no amount of scripting removes it. But a reel isn't really a video: it's a handful of cards, each held for a measured number of seconds. So we screenshot each card once and let ffmpeg do the motion between them. The result is sharper, reproducible, and needs nobody in the room.

The pictures are generated once, and without any words on them.

The image model draws a textless background; the company name is laid over it afterwards with real fonts. Two reasons: image models render Hindi and Telugu badly enough to be unusable, and a background with no words baked in serves all three languages from one generation instead of three.

07 — THE GUARDRAILSWhat stops it publishing something wrong

A pipeline this automatic needs to be able to say "no". Five checks do that, each answering a different question.

CheckThe question it answersWhen it runs
verifyDoes this company exist? Ask both exchanges.every daily run
dedupeIs this the same offer as one we already track? Matched on ticker, not name.every daily run
doctorWhat's missing, and what can be repaired from what we have?every daily run
validateIs this reel filmable right now — fields present, numbers fresh, still inside its window?every daily run
monitorDid anything change since last time, and should it have?3× daily
gradeDo our stored numbers still match the desk's?weekly

Three rules that are enforced structurally, not by discipline

  • The model never returns a number that reaches the sheet. For the trade levels on reel 7, the arithmetic is done first and then re-attached by ticker after the model answers — whatever numbers it wrote are discarded unread. A hallucinated price is overwritten, not trusted.
  • An IPO is identified by its ticker, not its name. Two rows for one company cost us real damage; both would have been caught instantly by symbol. PERNIASPOP is Purple Style Labs however the row spells it.
  • A verdict nobody wrote is not a verdict. The apply/avoid fields used to default to "apply", so every issue carried a buy call no analysis produced. They now default to empty, and readiness refuses to call the reel filmable without one.

08 — WHERE IT STANDSAutomated, manual, missing

auto

Data collection · deduplication · verification · financials · AI analysis · translation · the daily briefing · readiness · the watchdog · images · video rendering

needs you once

YouTube OAuth consent · creating the migration spreadsheet · the studio password · channel settings

not built

YouTube upload · the orchestrator that walks ready→render→upload · reel 7's on-screen scenes · bundled fonts for Docker

The one gap that matters.

Everything from "an IPO was announced" to "a finished mp4 with narration and a thumbnail sits on disk" now happens without a person. What's left is the upload — which needs a one-time Google consent, after which a stored token runs unattended forever.

Deeper detail lives in docs/BACKEND.md (commands and data flow) and docs/YOUTUBE-PLAYBOOK.md (packaging, monetisation, compliance). The code itself is heavily commented — most files open by explaining why they exist before what they do.
